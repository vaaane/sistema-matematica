Robótica · Programação em C

Do bloco → ao código

No mBlock você arrastava blocos. Agora você vai escrever as ordens pro robô em C — a linguagem de verdade. Parece difícil, mas são só algumas regras. Bora?

robo.c
#include <stdio.h>

int main() {
    printf("Oi, eu sou o robo!\n");
    return 0;
}
o que aparece na tela Oi, eu sou o robo!
As cores não são enfeite — cada tipo de pedaço tem sempre a mesma cor. Vai te ajudar a "ler" o código.

01 · O esqueleto

A estrutura de um programa

Todo programa em C começa praticamente igual. Decore esse esqueleto.

robo.c#include <stdio.h>   // liga as ferramentas de tela (printf, scanf)

int main() {        // aqui começa o programa

    // suas ordens vão aqui dentro

    return 0;       // avisa que deu tudo certo
}                  // aqui termina o programa
Pensa assim: o main() é a receita principal. Tudo que estiver entre as chaves { } é o "passo a passo" que o computador vai seguir, de cima pra baixo, uma linha por vez.
02 · Falar com a tela

printf — mostrar coisas

O printf é o programa "falando": ele escreve algo na tela.

printf("Bateria carregada!\n");
printf("Robo pronto pra correr.\n");
na telaBateria carregada!
Robo pronto pra correr.

Repare em três coisas que sempre aparecem: as aspas " " em volta do texto, os parênteses ( ) e o ponto e vírgula ; no final.

O \n é o "Enter". Ele pula pra próxima linha. Sem o \n, tudo sai grudado na mesma linha.
03 · Guardar valores

Variáveis — caixinhas com nome

Uma variável é uma caixinha onde o programa guarda um valor pra usar depois.

int idade = 13;        // caixinha de número inteiro
float velocidade = 2.5; // caixinha de número com vírgula
char letra = 'V';      // caixinha de UM caractere
Pensa numa caixa etiquetada: primeiro você diz que tipo de coisa cabe nela (int, float...), depois o nome da etiqueta (idade), e aí coloca o valor dentro com o =.

Depois de criada, você pode trocar o valor a qualquer hora: idade = 14; (sem repetir o tipo, porque a caixa já existe).

04 · Que tipo de coisa cabe

Os tipos de variável

Você precisa avisar o C que tipo de valor vai guardar. Os principais:

TipoImprime comPra que serveExemplo
int%dnúmero inteiro0, 42, -7
float%fnúmero com vírgula2.5, 8.75
double%lfvírgula mais preciso3.14159
char%cum caractere só'A', 'z'

Em C, vírgula de número é ponto: escreve-se 2.5, nunca 2,5.

05 · As lacunas do printf

%d, %f e os "espaços reservados"

Pra mostrar o valor de uma variável, você deixa uma lacuna no texto e diz qual variável preenche ela.

int pontos = 50;
printf("Voce fez %d pontos\n", pontos);
na telaVoce fez 50 pontos
O %d é uma janelinha vazia. O printf tira o valor da variável que está depois da vírgula e "encaixa" naquela janelinha. Inteiro usa %d; número com vírgula usa %f.
float nota = 8.5;
printf("Sua nota: %.1f\n", nota);  // .1f = 1 casa depois da virgula
na telaSua nota: 8.5
06 · Peça por peça

Anatomia de uma linha

Toque (ou passe o mouse) em cada pedaço pra ver o nome dele e por que está ali.

printf("Nota: %d\n", nota);
Toque numa peça acima 👆
Cada cor é um tipo de pedaço. Juntos eles formam uma ordem completa.
Dica: leia sempre da esquerda pra direita, igual uma frase.
07 · Ouvir o usuário

scanf — receber um valor digitado

Se o printf é o programa falando, o scanf é o programa ouvindo: ele espera você digitar algo e guarda numa variável.

int idade;
printf("Quantos anos voce tem? ");
scanf("%d", &idade);
printf("Voce tem %d anos!\n", idade);
Cuidado com o &! No scanf a variável vem com um & na frente (&idade). Ele é o "endereço" da caixinha — é onde o valor digitado vai ser guardado. Esquecer o & é o erro nº 1 de quem começa.
08 · A pontuação do código

; { } ( ) — os sinais que organizam tudo

Em C, esses sinais não são opcionais. Cada um tem um trabalho.

SinalNomeO que faz
;ponto e vírgulatermina uma ordem. É o "ponto final" de cada frase.
{ }chavesagrupam um bloco de ordens (o "corpo" do main, de um if...).
( )parêntesesguardam o que uma função recebe: printf(...), main().
" "aspas duplasmarcam o início e o fim de um texto.
Regra de ouro: tudo que abre precisa fechar. Abriu ( → fecha ). Abriu { → fecha }. Abriu " → fecha ". Conte os pares quando der erro!
09 · Tudo junto

Um programa completo

Um programinha que pede dois números e mostra a soma. Tudo que você aprendeu, junto:

soma.c#include <stdio.h>

int main() {
    int a, b, soma;

    printf("Digite dois numeros: ");
    scanf("%d %d", &a, &b);

    soma = a + b;
    printf("A soma e %d\n", soma);

    return 0;
}
exemplo de execuçãoDigite dois numeros: 7 5
A soma e 12

11 · Cola rápida

Checklist antes de rodar

  • Tem #include <stdio.h> no topo?
  • Toda linha de ordem termina com ; ?
  • Todo ( tem um ) e todo { tem um } ?
  • No scanf, a variável tem & na frente?
  • O %d/%f combina com o tipo da variável?
  • Tem um return 0; antes da última chave?
