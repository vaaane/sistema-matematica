Equação do 2º Grau

Álgebra · Teoria Turmas 8D–8H Aula de 07/10
1 O que é uma equação do 2º grau? Teoria

Equação do 2º grau é toda equação que pode ser escrita na forma abaixo. O nome vem do maior expoente da incógnita, que é 2 (o x²).

ax2 + bx + c = 0
com a ≠ 0
Coeficientes
a → coeficiente de x²  ·  b → coeficiente de x  ·  c → termo independente (sem letra)
a = 2 · b = 3 · c = −5
2x2 + 3x − 5 = 0
a = 1 · b = 0 · c = −9
x2 − 9 = 0
a = 3 · b = 6 · c = 0
3x2 + 6x = 0
a = −1 · b = 4 · c = 1
−x2 + 4x + 1 = 0
⚠️
Por que a ≠ 0? Se a = 0, o x² some e a equação vira do 1º grau. E lembre: quando o termo não aparece, o coeficiente é 0; quando a letra aparece sozinha, o coeficiente é 1 (ou −1).
2 Completa ou incompleta Teoria
Completa → b ≠ 0 e c ≠ 0
x2 − 5x + 6 = 0
Incompleta → b = 0
x2 − 16 = 0
Incompleta → c = 0
x2 − 4x = 0
Incompleta → b = 0 e c = 0
5x2 = 0
3 Raízes e fórmula de Bhaskara Teoria
Definição
As raízes (ou soluções) são os valores de x que tornam a igualdade verdadeira. Uma equação do 2º grau tem no máximo duas raízes reais.

Para encontrar as raízes, usamos a fórmula de Bhaskara, em dois passos:

1º passo — discriminante
Δ = b2 − 4ac
2º passo — raízes
x = −b ± √Δ2a
💡
O ± gera duas contas: uma com + (dá o x₁) e outra com − (dá o x₂).
4 O que o Δ nos diz Teoria

Antes mesmo de terminar a conta, o valor de Δ já revela quantas raízes reais a equação tem:

Análise do discriminante
Δ > 0 → duas raízes reais e diferentes
Δ = 0 → duas raízes reais e iguais (uma raiz só)
Δ < 0 → nenhuma raiz real (não existe raiz quadrada real de número negativo)
⚠️
Cuidado com o b negativo. Se b = −5, então b² = (−5)² = 25 (positivo) e −b = +5. Use sempre parênteses ao substituir.
5 Exemplo resolvido Prática
🧮 Exemplo
Resolva: x2 − 5x + 6 = 0
  1. Identifique os coeficientes: a = 1, b = −5, c = 6.
  2. Calcule o Δ: (−5)2 − 4 · 1 · 6 = 25 − 24 = 1. Como Δ > 0, teremos duas raízes diferentes.
  3. Aplique Bhaskara: x = 5 ± √12 · 1 = 5 ± 12
  4. Separe as duas contas: x₁ = 62 = 3  e  x₂ = 42 = 2.
Solução: S = {2, 3}
💡
Sempre verifique. Substitua a raiz na equação original: para x = 3 → 32 − 5 · 3 + 6 = 9 − 15 + 6 = 0 ✓
