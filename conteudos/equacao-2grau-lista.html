Equação do 2º Grau

Álgebra · Lista Turmas 8D–8H Aula de 07/10
Lembrete · Fórmulas
Forma geral: ax2 + bx + c = 0 (a ≠ 0)
Discriminante: Δ = b2 − 4ac
Bhaskara: x = −b ± √Δ2a
✏️ Exercícios Pratique

Tente resolver sozinho no caderno primeiro. Depois clique em “Ver resposta” para conferir a resolução.

1Médio
Calcule o discriminante (Δ) da equação x2 − 6x + 9 = 0 e diga quantas raízes reais ela possui.
Resolução

a = 1, b = −6, c = 9.

Δ = (−6)2 − 4 · 1 · 9 = 36 − 36 = 0.

Como Δ = 0, a equação tem duas raízes reais e iguais: x = 62 = 3.

Δ = 0 → uma única raiz: x = 3.

2Médio
Resolva a equação x2 + 2x − 15 = 0.
Resolução

a = 1, b = 2, c = −15.

Δ = 22 − 4 · 1 · (−15) = 4 + 60 = 64.

x = −2 ± √642 = −2 ± 82

x₁ = 62 = 3  e  x₂ = −102 = −5.

S = {−5, 3}

3Desafio
Resolva a equação 2x2 − 3x − 2 = 0.
Resolução

a = 2, b = −3, c = −2.

Δ = (−3)2 − 4 · 2 · (−2) = 9 + 16 = 25.

x = 3 ± √252 · 2 = 3 ± 54

x₁ = 84 = 2  e  x₂ = −24 = −12.

S = {−1/2, 2}
