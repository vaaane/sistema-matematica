Migração de Apelidos
Definir o apelido de cada aluno igual ao nome real
← Painel
O que faz: percorre todos os perfis e define apelido_ativo = nome do aluno. Limpa também apelidos pendentes/recusados para que cada aluno possa escolher um novo apelido depois, normalmente.
Reversível: os nomes reais não são alterados — só o campo de apelido. Os alunos podem trocar o apelido novamente pela tela de perfil.
Clique em "🔍 Analisar apelidos" para começar.
