Conferir datas de aplicação das avaliativas

Esta página só LÊ os dados (não altera nada). Lista todas as liberações em liberacoes_ativas e mostra quais estão SEM data de aplicação — que são as que você precisaria corrigir para o aviso de "faltou / presente" funcionar na ficha do aluno.

Como usar: salve este arquivo dentro da pasta do projeto (junto das outras páginas, mesmo nível que a pasta /js), e abra pelo servidor local (ex.: localhost:8080/conferir-datas.html). Faça login antes se as regras do Firebase exigirem.
